# Knowledge: Architecture

Persistent system intelligence for Zipscribe. Read before building any unit. Decisions here are settled unless a unit explicitly documents a pass-back.

## Architectural thesis

Zero-server, offline-capable, installable SPA (PWA). A **framework-agnostic engine** (pure TypeScript) does all media, inference, and export work inside Web Workers; a thin React shell renders state and dispatches commands; a service worker serves the app shell and runtime wasm offline. The split makes the hard parts (pipeline, timing math, clustering, serializers) testable in plain vitest without a browser.

```
┌─ main thread ─────────────────────────────────────────────┐
│ React UI (src/ui)   Zustand store (src/state)  commands   │
│        │ dispatch              ▲ events                    │
│        ▼                       │                           │
│ Engine facades (src/engine) — pure TS, DI-friendly         │
└───────┬────────────────────────────────────────────────────┘
        │ structured-clone messages (src/engine/protocol.ts)
┌───────▼────────────────────────────────────────────────────┐
│ Workers (src/workers)                                      │
│  media.worker.ts    — mediabunny demux → PCM → resample    │
│                       (tees PCM to ASR + diarize ports)    │
│  asr.worker.ts      — VAD + ASR engine (webgpu/wasm)       │
│  diarize.worker.ts  — pyannote-seg + embeddings + cluster  │
│  export.worker.ts   — frame render → VideoEncoder → mux    │
└────────────────────────────────────────────────────────────┘
┌─ service worker (sw.js, vite-plugin-pwa) ─────────────────┐
│ precache: app shell (html/js/css/fonts/icons)              │
│ runtime cache-first: /wasm/* (ORT, ffmpeg core, sherpa)    │
│ bypass: model hosts (transformers.js owns model caching)   │
└────────────────────────────────────────────────────────────┘
```

## Canonical domain model (engine/model.ts)

unit-01 creates `model.ts` and `protocol.ts` **verbatim** from the two blocks below. They are the contract: other units import, never redefine. A unit that needs a contract change records it under "Contract changes" in its report; the orchestrator updates this file first.

```ts
type Seconds = number;   // absolute media time, float, 3-decimal precision ceiling

interface WordToken {
  text: string;            // no leading/trailing whitespace; punctuation attached to the preceding word
  start: Seconds; end: Seconds;
  probability?: number;    // 0..1, only when the engine exposes it (registry flag `confidence`)
  speakerId?: string;      // word-level speaker truth (diarization); block.speakerId is the majority
  breakAfter?: boolean;    // manual line break after this word (Shift+Enter)
  timing?: 'asr' | 'aligned' | 'estimated' | 'manual'; // default 'asr'; imported captions start 'estimated'
}
interface CaptionBlock {
  id: string;              // crypto.randomUUID()
  start: Seconds; end: Seconds;
  text: string;            // derived: words joined by ' ' ('\n' where breakAfter) — see domain invariant 2
  words: WordToken[];      // invariant: sorted, within [start, end]
  speakerId: string;       // Speaker.id (majority of word speakerIds)
  confidence?: number;     // 0..1 mean word probability, absent when engine has no probabilities
  retimeFromWords?: boolean; // if true, text edits re-derive word timings (default false = timings frozen)
}
interface Speaker { id: string; label: string; color: string } // id `SPK_<n>` durable; label editable; color from palette
interface MediaFingerprint { name: string; size: number; durationMs: number; sampleHashes: [string, string, string] }
interface MediaAsset {
  id: string; name: string; kind: 'video' | 'audio';
  container: string; audioCodec: string | null; videoCodec: string | null;
  duration: Seconds; width: number; height: number; fps: number;   // audio-only: width = height = fps = 0
  fingerprint: MediaFingerprint;
}
interface CaptionStyle {
  fontFamily: string; fontWeight: 400 | 700; fontSizePct: number; // % canvas height
  textTransform: 'none' | 'lowercase' | 'uppercase';
  color: string; highlightColor: string; outlineColor: string; outlineWidth: number;
  backgroundColor?: string; backgroundOpacity: number;
  position: 'top' | 'center' | 'bottom'; marginVPct: number;
  alignment: 'left' | 'center' | 'right';
  maxLinesPerBlock: 1 | 2 | 3;
  highlightMode: 'none' | 'karaoke' | 'bold-active';
  showSpeakerBar: boolean;
  animationPreset?: string;
}
type OutputAspect = 'source' | '16:9' | '9:16' | '1:1' | '4:5';
interface TranslationEntry {
  text: string;            // may contain '\n' line breaks; no word timings (cue-level only)
  status: 'translated' | 'edited' | 'failed';
  sourceHash: string;      // hash of the source block.text it was made from; mismatch ⇒ stale
}
interface TranslationTrack {
  language: string;        // BCP-47 target, e.g. 'fr', 'zh-Hant'
  origin: 'machine' | 'imported' | 'manual';
  engine: 'chrome-translator' | null;
  entries: Record<string, TranslationEntry>; // keyed by source CaptionBlock.id — timing is always the source block's
}
interface Project {
  id: string; name: string; schemaVersion: number;
  asset: MediaAsset;
  blocks: CaptionBlock[];   // the SOURCE track (language = project.language)
  captionOrigin: 'none' | 'transcribed' | 'imported' | 'mixed';
  translations: TranslationTrack[]; // at most one per language
  speakers: Speaker[];
  speakerSource: 'none' | 'auto-beta' | 'manual';
  language: string | null;  // BCP-47 primary tag ('en', 'fr') of the source track; null = engine auto-detect pending
  modelId: ModelId | null;  // model that produced the transcript (provenance)
  style: CaptionStyle; outputAspect: OutputAspect;
  transcription: 'none' | 'partial' | 'complete'; // 'partial' after cancel/interrupt
  updatedAt: number;        // epoch ms
}
type ProjectSnapshot = Readonly<Project> & { snapshotVersion: number }; // immutable copy handed to export
```

## Worker protocol (engine/protocol.ts)

```ts
type Tier = 'T1' | 'T2' | 'T3' | 'T4';   // capability class (see Degradation tiers) — UI-facing
type Device = 'webgpu' | 'wasm';         // inference backend — engine-facing. Never call a Device a "tier".
type ModelId = string;                   // registry key, e.g. 'whisper-base_timestamped@608c49e6'
interface PcmChunk { startSec: Seconds; samples: Float32Array }   // 16 kHz mono f32, 1 s batches, transferable
type PcmSource = { kind: 'transfer'; buffer: ArrayBuffer } | { kind: 'stream'; port: MessagePort } // stream mandatory for long media
interface VadSegment { start: Seconds; end: Seconds }
interface RawSegment { start: Seconds; end: Seconds; text: string; words: WordToken[]; probability?: number }
interface DiarFrames { speakers: number; frames: { start: Seconds; end: Seconds; speaker: number; prob: number }[] }
interface PeaksData { bucketSec: number; min: Float32Array; max: Float32Array }
type EngineErrorCode =
  | 'MODEL_UNLOADED' | 'CACHE_CORRUPT' | 'NETWORK' | 'QUOTA_EXCEEDED'
  | 'GPU_OOM' | 'SESSION_LOST' | 'DECODE_STALL' | 'DIAR_SESSION_LOST'
  | 'UNSUPPORTED_MEDIA' | 'FFMPEG_REQUIRED' | 'ENCODER_UNSUPPORTED'
  | 'CANCELLED' | 'ENGINE_INTERNAL';
interface EngineError { code: EngineErrorCode; retryable: boolean; detail?: string } // detail: codes/numbers only — NEVER content (SECURITY-03)
type NoticeCode = 'TIER_DOWNGRADE' | 'MULTI_TRACK' | 'FFMPEG_FALLBACK' | 'WORKER_RECYCLED' | 'OFFLINE_MODEL_MISSING' | 'PLAYBACK_STALL' | 'PREVIEW_UNSUPPORTED';
interface Notice { code: NoticeCode; params?: Record<string, string | number> }  // UI maps code → copy

// Events shared by all workers
type JobEvent =
  | { t: 'job:progress'; jobId: string; processedSec: number; totalSec: number }
  | { t: 'job:done'; jobId: string }
  | { t: 'job:error'; jobId: string; error: EngineError }
  | { t: 'notice'; jobId?: string; notice: Notice };
type ModelEvent =
  | { t: 'model:confirm-required'; model: ModelId; bytes: number }         // > 100 MB gate (unit-03)
  | { t: 'model:progress'; model: ModelId; phase: 'download' | 'compile'; received: number; total?: number }
  | { t: 'model:ready'; model: ModelId; device: Device }
  | { t: 'model:error'; model: ModelId; error: EngineError };

// media.worker
type MediaRequest =
  | { t: 'probe'; jobId: string; file: File }
  | { t: 'decode'; jobId: string; file: File; ports: MessagePort[] }      // tee: identical PcmChunks to every port (ASR + diarize)
  | { t: 'cancel'; jobId: string };
type MediaEvent = JobEvent
  | { t: 'media:probed'; jobId: string; asset: MediaAsset }
  | { t: 'peaks:chunk'; jobId: string; firstBucket: number; min: Float32Array; max: Float32Array }
  | { t: 'decode:support'; jobId: string; path: 'webcodecs' | 'ffmpeg' };

// asr.worker
type AsrRequest =
  | { t: 'loadModel'; model: ModelId; device: Device }
  | { t: 'confirmDownload'; model: ModelId }
  | { t: 'transcribe'; jobId: string; pcm: PcmSource; sampleRate: 16000; language: string | null; resumeFromSec?: Seconds }
  | { t: 'cancel'; jobId: string } | { t: 'unload' };
type AsrEvent = JobEvent | ModelEvent
  | { t: 'vad:segments'; jobId: string; segments: VadSegment[] }
  | { t: 'job:segments'; jobId: string; segments: RawSegment[] };          // streamed batches, sorted

// diarize.worker
type DiarizeRequest =
  | { t: 'loadModels' }
  | { t: 'diarize'; jobId: string; pcm: PcmSource; sampleRate: 16000; vad?: VadSegment[]; maxSpeakers?: number }
  | { t: 'cancel'; jobId: string } | { t: 'unload' };
type DiarizeEvent = JobEvent | ModelEvent | { t: 'diar:frames'; jobId: string; frames: DiarFrames };

// export.worker
interface ExportSettings { format: 'mp4-burn-in'; width: number; height: number; fps: number }
type ExportRequest = { t: 'export'; jobId: string; snapshot: ProjectSnapshot; file: File; settings: ExportSettings } | { t: 'cancel'; jobId: string };
type ExportEvent = JobEvent | { t: 'export:result'; jobId: string; blob: Blob };
```

All timestamps produced by the engine are **absolute media seconds**; the UI never re-derives offsets. Sidecar exports (SRT/VTT/JSON/TSV) and caption-file parsing are pure main-thread functions, not worker jobs (files are KB–MB). Translation is not a worker job either — see the Translator API decision below.

```ts
// engine/captions — pure, main-thread
type CaptionFormat = 'srt' | 'vtt' | 'sbv' | 'ttml' | 'ass' | 'zipscribe-json';
interface ImportReport {
  format: CaptionFormat; encoding: string; cues: number; blocks: number;
  detectedLanguage: string | null;
  adjustments: { code: 'OVERLAP_CLAMPED' | 'ZERO_DURATION_FIXED' | 'TAGS_STRIPPED' | 'POSITION_DROPPED' | 'STYLE_DROPPED' | 'EMPTY_CUE_DROPPED' | 'CUE_UNMATCHED'; count: number }[];
}
type QcIssueCode = 'CPS_HIGH' | 'LINE_TOO_LONG' | 'TOO_MANY_LINES' | 'DURATION_SHORT' | 'DURATION_LONG' | 'GAP_TINY' | 'OUT_OF_MEDIA' | 'TRANSLATION_STALE' | 'TRANSLATION_MISSING';
interface QcIssue { code: QcIssueCode; blockId: string; track: 'source' | string; value: number }
```

## Settled technology decisions (with why)

| Decision | Choice | Why |
|---|---|---|
| Inference runtime | **Engine-abstracted registry** (`EngineKind: transformers-whisper \| sherpa-wasm \| cactus-whistle`); primary path `@huggingface/transformers@~3.8.1`, `device:'webgpu'`, per-module dtypes `{encoder_model:'fp32', decoder_model_merged:'q4'}`; non-primary engines gated on unit-02 measured spike | Only zero-server stack with Whisper + word timestamps + long-form chunking + HF CDN caching. 3.x pinned pending unit-02 leak measurement (see settings `version_pins`). sherpa-onnx WASM has an official non-streaming VAD+ASR path (`wasm/vad-asr`) → candidate engine host for Parakeet/Zipformer (native punctuation + token timestamps). |
| Model provenance | Every registry row pins `repo` + **`revision` (commit SHA)** + per-file SHA-256 | HF `main` moves; unpinned repos silently change weights and break checksums. HF returns `x-repo-commit` on resolve. |
| Runtime wasm hosting | onnxruntime-web, ffmpeg core, sherpa wasm **self-hosted under `/wasm`** (`env.backends.onnx.wasm.wasmPaths = '/wasm/'`), `numThreads = 1` | transformers.js defaults to loading ORT wasm from a CDN — breaks offline, privacy audit, and CSP. Single-thread matches no-COOP/COEP production. |
| Word timestamps | `onnx-community/whisper-*_timestamped` + `return_timestamps:'word'` | DTW-on-cross-attention; `_timestamped` exports ship the needed weights. Timings are approximate → UI must allow manual timing correction. Per-word probabilities are **not** in the ASR pipeline output as far as documented — `confidence` is engine-optional (verify in unit-02). |
| Long audio | Silero VAD → pack speech into ≤ 28 s windows cut only at silence → one pipeline call per window; internal `chunk_length_s:30, stride_length_s:5` only for continuous speech > 28 s | Whisper is a 30 s fixed window; silence cuts avoid duplicate/split words and bound memory. Leak containment = **ASR worker recycling** (terminate + respawn, resume from last committed window) on a cadence derived from unit-02's measured per-window GPU growth (transformers.js #1739 leaks inside a single pipeline call). |
| Diarization | pyannote-segmentation-3.0 (`AutoModelForAudioFrameClassification`, wasm fp32) + 3D-Speaker ERes2Net ONNX + agglomerative clustering (DIY). Run ERes2Net through the **same onnxruntime-web instance transformers.js bundles** (no second ORT copy); fallback candidate: sherpa-onnx WASM speaker-diarization | Components are permissively licensed on the Hub; a second ORT build would double wasm weight. Shipped as **beta** with manual reassign/rename UI. |
| Demux/mux | mediabunny (WebCodecs): read via `Input` + `BlobSource` + `AudioSampleSink` (`track.canDecode()` probes support); write via `Output` + `Mp4OutputFormat` + `CanvasSource` | mp4-muxer is deprecated in favour of mediabunny; reads lazily from a Blob (no full-file load). Subtitle tracks: **write-only** (reading unsupported). |
| Supported media | **Video:** MP4/M4V, MOV, MKV, WebM, MPEG-TS. **Audio (native, mediabunny + WebCodecs):** MP3, M4A/M4B (AAC), AAC (ADTS), WAV, FLAC, Ogg Vorbis (`.ogg/.oga`), Opus (`.opus`), WebM audio (`.weba`), Matroska audio (`.mka`). **Audio (ffmpeg.wasm fallback):** AIFF, ALAC-in-M4A, WMA, AMR/3GP, CAF — and any native-container codec the browser's `AudioDecoder` rejects. Per-browser matrix verified in unit-04 | Podcasts, voice memos, interviews and music arrive in these formats; mediabunny reads all of the native set, ffmpeg covers the long tail. |
| Playback & preview | `MediaClock` interface behind `SyncArbitrator`: **element clock** (`<video>`/`<audio>`, when `canPlayType` + a probe play succeed) or **decoded clock** (media worker decodes at the native rate → `AudioWorkletNode` ring buffer, `AudioContext.currentTime` is the clock; seek = restart decode at t). Audio-only projects render an **audio visualizer** on the preview stage (live FFT via `AnalyserNode`, drawn as a spectrum line) with the caption overlay on top. Video formats the `<video>` element can't play get an honest notice (decoded video playback = seed) | Audio files have no frames to show and several popular audio formats (AIFF, WMA, AMR, FLAC/Opus on older Safari) aren't playable by the media element — decoded playback makes every importable audio file previewable. |
| Decode fallback | single-threaded ffmpeg.wasm, lazy-loaded; preferred integration = mediabunny **custom decoder** so one pipeline serves both paths (verify in unit-04) | Covers codecs WebCodecs can't; single-threaded build avoids SharedArrayBuffer → **no COOP/COEP needed in production**. |
| Burn-in export | mediabunny `VideoSampleSink → OffscreenCanvas(overlay) → CanvasSource(H.264) + audio passthrough/AAC → Mp4OutputFormat` in `export.worker.ts` | All-client 1080p. AudioEncoder gap (Safari < 26) gates burn-in to the capable tier; sidecar export is always available. |
| Timeline rendering | custom canvas 2D (dpr-scaled), data-model hit-testing | 60 FPS drag/zoom with thousands of blocks; DOM blocks would thrash. |
| State | zustand + immer + zundo (undo ≥ 100) | One canonical mutable state + command history; React is a subscriber. View layer swappable behind `state/`. |
| Persistence | IndexedDB (idb): Project JSON + waveform peaks; media via File System Access handle (Chromium) / picker fallback, blob cache < 500 MB | Local-first; re-link file on reopen when handle is stale. |
| Caption import | Own parsers for SRT, WebVTT (incl. `<v>` voices → speakers), SBV, TTML/DFXP (text profile), ASS/SSA (dialogue text; override tags stripped), Zipscribe JSON; BOM/UTF-8/UTF-16 sniff with windows-1252 fallback; imported cue segmentation is **preserved** (no silent re-blockization); word timings estimated by character weight, upgradable by "Align to audio" (ASR words ↔ caption text alignment) | Users arrive with existing captions (YouTube exports, vendor SRTs) that need fixing, not re-transcribing. Formats are small text — no dependency needed. |
| Translation engine | `TranslationEngine` interface (shape from zip-captions ADR-013: `availability`, `ensurePair` (download, user-gesture), `translate`, `detectLanguage`, `dispose`); v1 backend = Chrome built-in **Translator API** + **LanguageDetector API** (Chrome 138+/Edge 148+ desktop). Runs on the **main thread** (API is Window-only, unavailable in workers); calls are async and inference runs in the browser, so the session batches work to keep the no-long-task gate. Pipeline ported from zip-captions v0.5.0 (`SegmentTranslationSession`: generation counter, per-pair LRU of ≤ 4 translator instances, strict failure semantics, ≤ 3 attempts per block, destroy-and-rebuild on `UnknownError`) | Same on-device, zero-upload approach proven in zip-captions; no model hosting, no new dependency. Unsupported browsers get honest gating; a transformers.js Opus-MT fallback is a seed (NLLB-200 is CC-BY-NC → excluded). |
| Offline + install | PWA via vite-plugin-pwa (Workbox): manifest (installable), precached shell, cache-first `/wasm`, `registerType:'prompt'` updates, `file_handlers` for OS "Open with" (Chromium) | Users expect a local tool to work on a plane; installation also improves storage durability. Models are never prefetched in the background — offline readiness is an explicit user action. |
| Hosting | Cloudflare Pages, static, `public/_headers` | Zero-server fits the privacy thesis; `_headers` for cache + CSP. |

## Degradation tiers (feature-detect at boot, `engine/model/capability.ts`)

| Tier | Detect | ASR | Diarize | Media | Export |
|---|---|---|---|---|---|
| **T1 WebGPU** | `navigator.gpu` + adapter ok | webgpu fp32/q4 | wasm | WebCodecs | sidecars + MP4 burn-in |
| **T2 WASM-CPU** | no usable webgpu adapter | wasm q8 (tiny/base) | wasm | WebCodecs | sidecars + MP4 burn-in (slow) |
| **T3 Limited** | no WebCodecs `AudioDecoder` or `AudioEncoder` (Safari < 26) | wasm | wasm | ffmpeg.wasm | sidecars only (WebM burn-in = seed) |
| **T4 Blocked** | no WASM SIMD, or `navigator.deviceMemory` reported < 4 | hard-stop screen with requirements list | — | — | — |

`navigator.deviceMemory` is Chromium-only and coarse; when undefined, do not block on memory. Offline is orthogonal to tier: an offline T1 session transcribes only with an already-cached model.

**Media kind overrides tier for export:** an audio-only project (`asset.kind === 'audio'`) never shows burn-in — not disabled, absent — on every tier; it exports sidecars only. The output-aspect selector is also hidden for audio projects (the visualizer stage is 16:9).

## Cross-cutting invariants

1. Main thread: no inference, no demux, no encode — only UI work (gate: no > 50 ms long tasks attributable to engine during transcription). Sole exception: Translator/LanguageDetector API calls, which must be made from a Window; they are awaited in batches with yields between them and held to the same 50 ms gate.
2. Engine modules receive dependencies (sessions, fs handles, clocks) via constructor/factory injection — mockable in vitest.
3. Every destructive edit is a command in history (undoable); autosave after ≥ 2 s idle.
4. Timestamps monotonic within a block; block.start < block.end; speakerId always resolves to a Speaker.
5. All model downloads go through the Cache API (`zipscribe-models`) with SHA-256 verification against the registry, at a pinned `revision`. transformers.js caching must be routed through a custom cache (`env.useCustomCache`/`env.customCache` — verify names for the pinned version) so verification is ours, not best-effort.
6. **SECURITY-03 (privacy invariant, carried from zip-captions):** transcript text and audio-derived strings never appear in logs, telemetry, error `message`/`detail` fields, or crash reports — log codes/types only; redaction tests enforce.
7. Punctuation/capitalization/confidence/language-detect are engine-dependent registry flags — UI copy and serializers must not promise what the selected engine doesn't emit.
8. **Network allowlist:** at runtime the app contacts only `self` and `settings.yml operations.model_hosts`. CSP `connect-src` and the Playwright request audit use the same list.
9. **Offline:** after first load, every feature that doesn't need a not-yet-downloaded model works with the network disabled.
